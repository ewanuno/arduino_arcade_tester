this is a simple arduino project to test arcade redemption ticket dispensers and coin acceptors

its been designed to work with Tong li animation tw-950 coin acceptors and TL-002IV ticket distributors.

it should work with others, but if they use 12v signals then it will probably cook your arduino. 

Max vibe coded it and i helped him to get it working and designed the PCB

the lcd is a generic 1602iic
